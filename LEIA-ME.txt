TERRAS RARAS — PRIMEIRA VERSÃO
================================

ARQUIVOS
- index.html: página principal.
- style.css: aparência e adaptação para celular/desktop.
- app.js: contador e ações dos botões.
- manifest.json: configuração de instalação PWA.
- sw.js: Service Worker usado pelo navegador.
- ws.js: cópia com o nome alternativo solicitado.
- icon.svg: ícone do aplicativo.
- assets/terras-raras-banner.jpg: imagem principal.

COMO PUBLICAR NO GITHUB PAGES
1. Crie um repositório no GitHub.
2. Envie todos os arquivos e a pasta assets, mantendo a estrutura.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch main e a pasta /(root), depois salve.
6. Aguarde a publicação e abra o endereço fornecido pelo GitHub.

IMPORTANTE SOBRE O SALDO
Esta é uma demonstração de interface: começa com 150 TR (100 + 50 de bônus).
Cada clique em “Ganhe mais 50 TR” acrescenta 50 TR e salva o saldo no navegador
usando localStorage. O saldo não é compartilhado entre aparelhos/usuários e não
é uma carteira real. Para saldo seguro, login e recompensas reais, será necessário
conectar um backend e validar os ganhos no servidor.

PWA / OFFLINE
A instalação e o Service Worker exigem HTTPS (o GitHub Pages fornece HTTPS).
O cache funciona depois que o app é aberto online pelo menos uma vez.
